# Inventaire honnête du contenu de ce handoff

## Fournis et vérifiés

- `assets/reference/master-characters-APPROVED.png` : image 1536×1024, planche représentant les deux héros et des propositions de customisation. **C'est la référence visuelle immuable.**
- `assets/reference/art-and-three-themes-APPROVED.png` : image 1536×1024, planche de direction artistique avec trois environnements.
- `assets/existing-app/` : trois captures du prototype Claude d'avant refonte (home, méthode guitare, sélection de thèmes). Elles sont des photographies d'interface, pas le code source.
- `reference_only/demo/` : mini démonstrateur HTML autonome. Fonctions limitées : choix avatar + thème + rendu simple + localStorage. Il n'implémente pas les quêtes, gacha ou audio de l'app réelle.
- `reference_only/previews/` : captures de cette mini démo, uniquement contextuelles.

## Manquants (ne jamais inventer)

- Export complet du code de l'artefact Claude initial.
- Sources Photoshop/Illustrator/Krita **multicouches** fidèles aux héros.
- Sprites master full-body HD RGBA réellement propres + accessoires alignés et interchangeables.
- Tests de reconnaissance audio et preuve de progrès musicaux.
- Test de déploiement public iOS/Android/web de l'app réelle.

## Attention aux images

Ne pas publier directement les concept sheets comme fond définitif d'application, ne pas utiliser leur recadrage comme démonstration d'un sprite articulable, ne pas prétendre que toutes les tenues sont déjà exportées. Le rendu final ne doit pas être en dessous de la qualité de référence.
