# ADR léger — décisions verrouillées et marge du lead

- **A-001 / locked** — planche originale = référence artistique ; pas de SVG improvisé pour la « remplacer ».
- **A-002 / locked** — deux avatars de base ; tous les objets cosmétiques restent optionnels et n'améliorent pas une compétence musicale.
- **A-003 / locked** — trois thèmes uniquement Sakura, Cyberpunk, Ombre.
- **A-004 / locked** — le code de l'artefact existant fait foi ; adaptation incrémentale, pas réécriture.
- **A-005 / locked MVP** — pas de tirages aléatoires monétisés ; monnaie virtuelle gagnée à l'entraînement.
- **A-006 / decision by tech lead** — framework, structure et persistance à décider après audit du vrai dépôt ; éviter de surarchitecturer.
- **A-007 / assumption to verify** — niveau de maturité de la reconnaissance audio, existence réelle de l'authentification et disponibilité d'un backend sont inconnus.
- **A-008 / legal gate** — l'art généré doit avoir des droits d'utilisation clarifiés avant commercialisation, sans copier d'assets Postknight.

Documenter tout nouveau choix majeur dans le journal de décisions du projet. Pas d'abonnement logiciel imposé si une alternative adaptée existe.
