# Ce que Claude Code vérifie à la réception
- [ ] Noms de fichiers exacts (ceux des prompts).
- [ ] Dimensions exactes (1920×1080, 1080×1920, 1024×1280, 256×256).
- [ ] Personnages et calques : PNG RGBA, coins transparents, pas de damier dessiné, pas de halo blanc.
- [ ] Calques : même canevas que le master ; empilés, ils redonnent le master (écart mesuré pixel par pixel).
- [ ] Pieds à (512, 1170) ; même échelle garçon/fille.
- [ ] Décors : aucun personnage ni texte ; zone centrale basse calme ; sol plat sous les pieds.
- [ ] Mobile : vraie composition verticale, pas un recadrage.
- [ ] Fidélité au style de la planche approuvée (validation finale : le fondateur).
