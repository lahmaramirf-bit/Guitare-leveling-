# 01 — Source de vérité / périmètre / décisions

**Source fonctionnelle :** le dépôt Claude Code v0.2 — à auditer. Les informations fournies par Claude sont un état déclaré, pas une vérification de notre part.

**Source artistique :** `assets/references/master-characters-APPROVED.png` (ancienne planche approuvée) et **les deux fichiers source haute résolution** désormais retenus comme masters d'affichage de base. La première définit l'ADN visuel ; les seconds représentent les avatars officiels de base pour l'intégration statique.

**Priorités non négociables** : chibi anime illustré soigné (la DA initiale citait env. 2,4 têtes, mais **les proportions visuelles des deux nouveaux PNG officiellement aimés priment : ne pas les étirer artificiellement**), musicien/musicienne d'académie fantasy (pas chevalier), garçon brun ébouriffé au casque, fille corail à la barrette musicale, unité graphique navy/crème/or/corail, contours précis, ombres douces.

**Décisions produit** : choix du personnage au premier onboarding, puis sauvegarde durable ; hub central où le héros est pleinement visible ; Sakura, Cyberpunk, Ombre sont trois **mondes visuels** complets ; pas de gacha, boutique de cosmétiques gagnés grâce à la pratique ; réaction en jeu à la progression.

**Périmètre de ChatGPT** : DA / assets / recette artistique / brief. **Pas de code applicatif**. Claude Code assure l'implémentation et les tests du projet utilisateur.

**Ce qui N'EST PAS approuvé comme production** : anciens SVG simplifiés, crops basse résolution de planche, variantes générées sans contrôle, accessoires qui ne sont pas alignés sur le master.

**Risque principal** : les deux PNG de base sont *aplatis*. Le rig et la customisation avec pièces indépendantes ne sont pas techniquement disponibles sans production d'un vrai fichier source multicouche. On pourra les afficher, mais pas leur faire jouer de la guitare avec les bons bras seulement à partir du PNG.
